## ✨ Features

- 🔬 **AI-Powered Detection**: Deep learning model with 95%+ accuracy
- 🌐 **Web Interface**: User-friendly Streamlit web application
- 📱 **Mobile Responsive**: Works on desktop and mobile devices
- 💊 **Treatment Recommendations**: Detailed solutions for each disease
- 📊 **Confidence Scores**: Visual confidence indicators for predictions
- 🛡️ **Prevention Guidelines**: Long-term prevention strategies
- 🔍 **Disease Library**: Comprehensive information about all supported diseases
- ⚡ **Real-time Prediction**: Instant results within seconds

## 🦠 Supported Diseases

| Disease | Type | Key Symptoms | Risk Level |
|---------|------|--------------|------------|
| **Bacterial Blight** | Bacterial | Water-soaked lesions, yellow streaks | High |
| **Blast** | Fungal | Diamond-shaped lesions, gray centers | Very High |
| **Brown Spot** | Fungal | Oval brown spots, yellow halos | Medium |
| **Tungro** | Viral | Yellow-orange leaves, stunted growth | High |
